7

🌐 Cloudflare Tunnel（免費外網穿透）

LINE 伺服器需要公開 HTTPS 網址才能打到你的電腦，用 Cloudflare Tunnel 一鍵解決，不需帳號！

# 安裝
winget install --id Cloudflare.cloudflared
# 啟動（會產生公開 HTTPS 網址）
cloudflared tunnel --url http://localhost:8000
# → https://xxxxx.trycloudflare.com
8

🔗 設定 LINE Webhook

  1. 前往 LINE Developers Console → Messaging API 分頁
  2. 在 Webhook URL 填入：https://xxxxx.trycloudflare.com/callback
  3. 開啟 Use webhook 開關（切為 ON）
  4. 點擊 Verify，出現 Success 即成功
  5. 關閉 Auto-reply messages（自動回應） 設為停用
